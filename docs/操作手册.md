# 操作手册

本文档面向车间操作人员，用来说明程序怎样启动、怎样选择输入 Excel、运行过程中怎么看进度、运行完成后到哪里找结果。

总表 Excel 的详细解释、生产指令报告的详细解释、现场注意事项已经拆成单独文件：

| 文件 | 用途 |
|---|---|
| [总表Excel说明](总表Excel说明.md) | 说明 `*_混合宽度结果.xlsx` 每个 Sheet 和关键字段怎么理解 |
| [生产指令报告说明](生产指令报告说明.md) | 说明每个 `*_cutting_report.txt` 生产指令报告怎么执行 |
| [注意事项](注意事项.md) | 说明运行和生产过程中容易出错、需要特别提醒的事项 |

## 1. 运行前准备

运行前先准备好输入 Excel。

当前程序读取第一个 Sheet，并按前四列顺序读取数据。前四列必须固定为：

| 第几列 | 内容 | 说明 |
|---|---|---|
| 第 1 列 | 品名 | 例如酸洗、高强度板等 |
| 第 2 列 | 规格 | 必须写完整三段：`厚度*尺寸1*尺寸2`，例如 `0.7*328*340` |
| 第 3 列 | 片数 | 订单片数 |
| 第 4 列 | 重量 | 该规格订单总重量，交付使用时统一按 `kg` 填写 |

注意：

1. 程序主要按前四列顺序读取，不要把 `规格`、`片数`、`重量` 调换位置。
2. 表头建议写成 `品名、规格、片数、重量`，便于人工检查。
3. `规格` 里的厚度、尺寸单位都按 `mm`。
4. 重量列统一按 `kg` 填写，不要一部分填 kg、一部分填吨。
5. 不要在程序运行中移动、删除或重命名输入 Excel。

## 2. 启动程序

正常交付给车间使用时，直接双击：

```text
run_client_workflow.bat
```

启动后会弹出 Excel 文件选择窗口。

操作步骤：

1. 双击 `run_client_workflow.bat`。
2. 等待弹出文件选择窗口。
3. 选择本次要排刀的 Excel 文件。
4. 点击打开。
5. 程序开始自动运行。

运行过程中会出现命令行窗口。请不要关闭这个窗口。

如果关闭命令行窗口，程序会被中断，可能只输出前面几组结果，后面的分组不会继续计算。

## 3. 运行进度怎么看

程序运行时会显示类似下面的进度：

```text
############------  21/42  50.00% 开始：G021 酸洗
#############-----  21/42  50.00% 完成：G021 酸洗
```

各部分含义如下：

| 显示内容 | 含义 |
|---|---|
| `21/42` | 一共 42 个分组，当前处理到第 21 个 |
| `50.00%` | 当前完成进度 |
| `开始` | 正在开始计算该分组 |
| `完成` | 该分组已经成功输出 |
| `失败` | 该分组未能生成可生产方案 |

如果最后显示：

```text
workflow completed successfully.
```

表示程序流程已经正常结束。

注意：这句话表示程序已经跑完，不代表所有分组都一定成功。是否有失败组，要看总表或命令行最后的汇总。

## 4. 输出文件在哪里

每次运行会在 `outputs/client_runs/` 下面生成一个新的结果文件夹。

文件夹名称一般包含输入文件名和运行时间，例如：

```text
outputs/client_runs/实际生产状态表_20260512_111034/
```

其中：

| 内容 | 含义 |
|---|---|
| `实际生产状态表` | 本次输入 Excel 的名称 |
| `20260512_111034` | 运行时间，表示 2026 年 05 月 12 日 11:10:34 |

每次运行都会生成新的文件夹，旧结果不会被覆盖。

## 5. 输出文件有哪些

运行完成后，常见输出包括：

| 输出内容 | 用途 |
|---|---|
| `*_混合宽度结果.xlsx` | 本次运行总表，查看全部分组成功、失败、补切和汇总数据 | 
| `排版图与报告/` | 每个成功分组的排版图和生产指令报告 |
| `*_cutting_report.txt` | 文本生产指令报告，指导具体怎么排刀、走料、核对产出 | 
| `*_cutting_plan.png` | 排版示意图，辅助确认刀位和宽度占用 | 
| `run_client_workflow.log` | 运行日志，出错时排查用 | 

车间实际生产时，一般重点看每组的 `*_cutting_report.txt`。

调度或复核时，先看 `*_混合宽度结果.xlsx`。

## 6. 推荐查看顺序

建议按下面顺序查看：

1. 先打开 `*_混合宽度结果.xlsx`。
2. 查看 `主流程汇总`，确认是否有失败组。
3. 如果有失败组，先处理失败组，不要直接下发全部任务。
4. 对成功分组，进入 `排版图与报告/`。
5. 打开对应分组的 `*_cutting_report.txt`。
6. 按生产指令报告执行排刀和走料。
7. 需要辅助确认刀位时，再打开对应的 `*_cutting_plan.png`。

## 7. 常见异常处理

| 现象 | 处理方式 |
|---|---|
| 没有弹出 Excel 选择窗口 | 重新双击 `run_client_workflow.bat`；仍不弹出时联系维护人员 |
| 只输出了前几组结果 | 检查运行时是否关闭过命令行窗口；重新完整运行一次 |
| 命令行显示有失败组 | 打开总表查看 `主流程汇总` 和 `无法承接分组` |
| 找不到输出文件 | 到 `outputs/client_runs/` 里找最新时间的文件夹 |
| TXT 报告显示错位 | 用记事本、VS Code、Notepad++ 等等宽字体查看 |
| Excel 打不开或读取失败 | 检查输入 Excel 是否被占用、损坏或格式不符合要求 |

## 8. 交接时重点说明

给现场人员交接时，重点说明以下几句话：

1. 双击 `run_client_workflow.bat` 后选择本次 Excel。
2. 程序运行时不要关闭黑色命令行窗口。
3. 输入 Excel 前四列顺序必须是 `品名、规格、片数、重量`。
4. 规格写 `厚度*尺寸1*尺寸2`，重量统一按 kg。
5. 跑完后先看总表有没有失败组。
6. 成功组按对应 TXT 生产指令报告执行。
7. 数量按走料长度和刀数核对，重量主要用于吨位核算。
8. 遇到失败组或报告异常，不要直接生产，先交给调度或技术人员复核。
