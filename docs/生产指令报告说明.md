# 生产指令报告说明

本文档说明每个 `*_cutting_report.txt` 生产指令报告怎么看。该报告面向车间执行人员，一组一个文件。

## 1. 报告在哪里

报告位于本次运行目录下：

```text
outputs/client_runs/<输入文件名>_<运行时间>/排版图与报告/width_xxxx/
```

例如：

```text
G001_stage_based_cutting_report.txt
G001_stage_based_cutting_plan.png
```

`G001` 是分组编号，`width_1250` 表示该组最终使用 1250 mm 母卷。

建议用记事本、VS Code 或 Notepad++ 打开 TXT 报告，使用等宽字体查看。

## 2. 报告结构

报告一般包含五部分：

```text
1. 生产任务信息
2. 订单与产出核对
3. 排刀执行说明
4. 换刀与补切提示
5. 车间确认栏
```

## 3. 生产任务信息

这一部分是本组总体信息。

| 字段 | 说明 |
| --- | --- |
| 任务编号 | 分组编号，例如 `G001` |
| 品名 | 本组品名 |
| 母卷规格 | 厚度和母卷宽度 |
| 输入重量单位 | 输入表重量单位，当前按 kg 读入，报告换算为吨 |
| 订单重量合计 | 本组输入订单重量合计 |
| 总走料长度 | 本组所有阶段总走料长度 |
| 预计用料重量 | 本组全部母卷材料预计用量 |
| 面积利用率 | 成品面积 / 母卷消耗面积 |
| 生产阶段数 | 本组需要几个阶段执行 |

## 4. 订单与产出核对

这一部分用于核对订单数量和当前方案产出数量。

| 字段 | 说明 |
| --- | --- |
| 产品编号 | 报告内编号，例如 `T1`、`T2` |
| 规格 mm | 产品尺寸 |
| 订单数量 | 输入表要求数量 |
| 本单产出 | 当前方案预计产出数量 |
| 差异 | 本单产出 - 订单数量 |
| 处理说明 | 对差异的说明 |

差异判断：

| 差异 | 含义 |
| --- | --- |
| `0` | 正好满足订单 |
| 正数 | 多产，需确认库存或余量处理 |
| 负数 | 少件，需要补切或人工处理 |

注意：当前程序已经对阶段式排刀中的缩放余数做了同刀位续切补足。能在同一刀位继续走料补足的，不会再误写成单独补切。

## 5. 排刀执行说明

这是车间最重要的部分。每个阶段表示一组刀位连续走料。

常见字段：

| 字段 | 说明 |
| --- | --- |
| 阶段 | 第几段连续走料 |
| 排刀组合 | 本阶段刀位组合，例如 `340 + 340 + 340` |
| 刀数 | 本阶段有几道刀 |
| 占用宽度 | 产品占用的母卷宽度 |
| 边部余宽 | 母卷剩余宽度 |
| 定尺长度 | 产品沿走料方向的长度 |
| 走料长度 | 本阶段需要连续走料的长度 |
| 预计用料重量 | 本阶段整段母卷预计用料重量 |
| 刀位累计位置 | 从一侧开始累计的刀位位置 |

车间执行时重点看：

```text
排刀组合
刀数
刀位累计位置
走料长度
```

## 6. 阶段产出表

阶段下方会有产出表：

```text
+----------+----------+------------+--------------+--------------+----------+
| 产品编号 | 每道产出 | 本阶段产出 | 产出重量(吨) | 单道尾料(mm) | 说明     |
+----------+----------+------------+--------------+--------------+----------+
| T1       | 13599    | 40797      | 25.000613    | 0            | 3 道并切 |
+----------+----------+------------+--------------+--------------+----------+
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| 产品编号 | 对应订单核对中的 `T1`、`T2` |
| 每道产出 | 每一道刀能产出的件数 |
| 本阶段产出 | 本阶段该产品总产出件数 |
| 产出重量(吨) | 按输入订单重量折算的成品重量 |
| 单道尾料(mm) | 每道最后不足一件的尾料长度 |
| 说明 | 并切道数 |

## 7. 示意图

报告中会有文字示意图：

```text
示意图：母卷宽度 1250 mm | T1 340 | T1 340 | T1 340 | 余宽 230
```

含义：

| 内容 | 说明 |
| --- | --- |
| 母卷宽度 1250 mm | 使用 1250 mm 母卷 |
| `T1 340` | 一个 T1 刀位，占宽 340 mm |
| 余宽 230 | 边部剩余 230 mm |

PNG 图片用于辅助复核，最终执行仍以 TXT 报告的刀位和走料长度为准。

## 8. 换刀与补切提示

这一部分提示生产安排：

| 内容 | 说明 |
| --- | --- |
| 换刀顺序 | 按阶段编号顺序执行 |
| 补切要求 | 如果有少件，会列出需要补切的产品和数量 |
| 多产说明 | 如果有多产，会列出多出的产品和数量 |
| 注意事项 | 阶段内不要随意改变刀位组合 |

如果补切要求为 `无`，说明本报告内数量已经满足订单或只存在可接受的多产。

## 9. 重量口径

报告里有两类重量：

| 重量 | 含义 |
| --- | --- |
| 预计用料重量 | 整段母卷走料重量，包含成品、余宽和尾料 |
| 产出重量 | 成品重量，按输入订单重量分摊 |

预计用料重量：

```text
母卷宽度 × 走料长度 × 厚度 × 组密度
```

组密度由输入表反算得到：

```text
组密度 = 本组订单总重量 ÷ 本组订单总体积
```

同一组有多个产品时，使用本组所有产品的体积加权密度。

产出重量：

```text
输入订单重量 / 订单数量 × 本阶段产出数量
```

数量是否够，按走料长度和定尺长度判断，不按重量判断。

## 10. 车间确认栏

最后的确认栏用于现场记录。

| 栏位 | 用途 |
| --- | --- |
| 排刀确认 | 刀位、宽度、阶段确认 |
| 生产确认 | 实际生产确认 |
| 数量核对 | 产出数量核对 |
| 补切确认 | 如果有补切，在这里确认 |
| 日期 | 生产日期 |
