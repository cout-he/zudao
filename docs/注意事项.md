# 注意事项

本文档汇总现场使用时需要特别注意的问题。目的是避免误操作、误读报告和数量对不上。

## 1. 运行程序注意事项

| 注意事项 | 原因 |
|---|---|
| 运行前保存并关闭输入 Excel | 避免程序读到旧数据，或文件被 Excel 占用 |
| 双击 `run_client_workflow.bat` 后不要关闭命令行窗口 | 关闭窗口会中断程序，导致只输出部分分组 |
| 每次运行后看最新时间的输出文件夹 | 程序每次都会生成新的运行目录 |
| 不要在程序运行中改输入表 | 程序已经开始读取和计算，运行中修改不会可靠生效 |

## 2. 输入表注意事项

当前程序读取第一个 Sheet，并按前四列顺序读取。前四列必须是：

| 第几列 | 内容 | 要求 |
|---|---|---|
| 第 1 列 | 品名 | 同一类材料名称尽量一致 |
| 第 2 列 | 规格 | 使用 `厚度*尺寸1*尺寸2`，例如 `0.7*328*340` |
| 第 3 列 | 片数 | 必须是正数 |
| 第 4 列 | 重量 | 交付使用时统一按 kg 填写 |

特别注意：

1. 程序主要按列顺序读取，不要调换前四列。
2. 表头建议写成 `品名、规格、片数、重量`，方便人工核对。
3. 厚度和尺寸单位均按 `mm`。
4. 重量单位统一按 `kg`，不要在同一张表里混用 kg 和吨。
5. 卷料、特殊规格写法、无法解析的规格会进入剔除明细，不会直接参与排刀。

## 3. 生产执行注意事项

| 注意事项 | 说明 |
|---|---|
| 按 TXT 生产指令报告执行 | 每个成功分组都有单独报告 |
| 阶段内不要随意改变刀位组合 | 报告中的产出数量按该阶段刀位和走料长度计算 |
| 数量按走料长度和定尺长度核对 | 一刀能出多少件由 `刀数 × floor(走料长度 / 定尺长度)` 决定 |
| 重量不能用来判断件数是否够 | 重量只用于吨位、用料和成本核算 |
| 有补切提示时必须单独确认 | 补切数量需要调度安排 |
| 有失败组时不要直接下发全部任务 | 失败组需要人工复核、外协、改规格或更换母卷 |

## 4. 关于密度和重量

程序里有两种重量口径：

| 重量 | 口径 |
|---|---|
| 预计用料重量 | 用母卷宽度、走料长度、厚度和钢材密度计算 |
| 产出重量 | 用输入表的订单重量按产出数量折算 |

预计用料重量现在优先使用输入表反算出的密度：

```text
组密度 = 本组订单总重量 ÷ 本组订单总体积
```

同一组里如果有多个产品，程序使用体积加权后的组密度。也就是用本组所有产品的总重量除以总体积，而不是简单取某一个产品的密度。

这样做的原因是：同一组通常是同一品名、同一厚度，实际应当使用同一种原料密度；但输入表里不同产品的重量可能有四舍五入，单个产品反算密度会有轻微差异。用总体积加权密度，可以减少小规格四舍五入对原料重量的影响。

如果输入重量缺失、规格无法解析，程序才会回退使用默认钢材密度：

```text
7.85 t/m³
```



需要记住：

```text
数量看走料长度
重量看吨位核算
```

## 5. 关于同刀位续切

大批量阶段式排刀为了加快计算，会对数量做缩放。缩放可能产生余数，例如：

```text
订单 146 件，缩放后先算出 144 件
```

如果同一阶段同一刀位可以继续走料，程序会自动延长该阶段走料长度，把少的数量补足。

现场理解方式：

| 情况 | 处理 |
|---|---|
| 同刀位能继续走料 | 不需要重新换刀，继续走料补足 |
| 报告显示补切要求为无 | 按当前报告执行即可 |
| 报告明确显示需要补切 | 按补切提示另行安排 |

修正后报告会显示增加后的走料长度和正确产出数量。

## 6. 失败组处理

如果总表显示失败组，先看：

```text
主流程汇总
无法承接分组
```

常见原因：

| 原因 | 处理方式 |
|---|---|
| 规格宽度超过最大候选母卷宽度 | 换更宽母卷、外协或改规格 |
| 多规格组合没有可行刀位 | 人工复核或调整生产安排 |
| 输入规格异常 | 回到输入表检查规格写法 |
| 数量或重量缺失 | 补齐输入表后重新运行 |

失败组不能直接按程序报告生产，因为失败组通常不会生成完整生产指令报告。

## 7. 报告显示不齐

TXT 报告使用文本边框表格。查看时建议使用等宽字体。

推荐打开方式：

| 工具 | 说明 |
|---|---|
| 记事本 | 可以查看，但对齐效果可能一般 |
| VS Code | 对齐效果较好 |
| Notepad++ | 对齐效果较好 |
| 等宽字体 | 例如 Consolas、Courier New |

如果复制到微信、普通富文本软件或非等宽字体环境，表格可能看起来错位。

## 8. 交接建议

给车间交接时，建议反复强调三句话：

```text
先看总表有没有失败组。
生产按 TXT 指令报告执行。
数量看走料长度，重量只做核算。
```
