# 总表 Excel 说明

本文档说明 `*_混合宽度结果.xlsx` 怎么看。总表用于汇总整次排刀结果，适合调度、班组长、复核人员查看。

## 1. 总表位置

每次运行完成后，总表位于：

```text
outputs/client_runs/<输入文件名>_<运行时间>/*_混合宽度结果.xlsx
```

打开后会看到多个 Sheet。现场最常用的是：

| Sheet | 用途 |
| --- | --- |
| 主流程汇总 | 最重要，一行一个分组，查看是否完成、补切、超产、失败原因 |
| 宽度分配汇总 | 查看各母卷宽度用了多少组、总走料长度和利用率 |
| 单规格结果 | 单规格直接排的详细结果 |
| 多规格结果 | 多规格混排的详细结果 |
| 无法承接分组 | 失败且现有母卷宽度无法承接的分组 |

其他 Sheet 多用于复核和追溯。

## 2. 主流程汇总

`主流程汇总` 是最重要的页。一行代表一个分组。

| 字段 | 说明 |
| --- | --- |
| 分组编号 | 例如 `G001`，对应报告和图片文件名 |
| 品名 | 输入表中的品名 |
| 厚度 | 材料厚度，单位 mm |
| 规格种数 | 本组包含多少种规格 |
| 处理方式 | 单规格直接排或多规格优化 |
| 状态 | `完成` 表示可查看报告；`失败` 表示不能直接下发 |
| 母板宽度 | 本组最终选用的母卷宽度 |
| 最优朝向 | 产品横向放置方向，供复核参考 |
| 订单总片数 | 本组订单总需求件数 |
| 算法产出总片数 | 当前方案预计产出件数 |
| 补切数 | 少于订单的件数 |
| 超产数 | 多于订单的件数 |
| 总重量 | 输入表中本组重量合计 |
| 总消耗长度(mm) | 本组预计母卷走料总长度 |
| 真实利用率(%) | 成品面积 / 母卷消耗面积 |
| 条带数/阶段数 | 单规格多为条带数，多规格阶段排刀为阶段数 |
| 业务结论 | 程序给出的处理结论 |
| 推荐动作 | 给调度和车间的处理建议 |
| 图像输出 | PNG 排版图路径 |
| 报告输出 | TXT 生产指令报告路径 |
| 备注 | 宽度选择、朝向、失败原因等说明 |

## 3. 推荐动作怎么理解

| 推荐动作 | 含义 | 现场处理 |
| --- | --- | --- |
| 按当前方案直接下发生产 | 数量满足订单，没有补切要求 | 可按报告生产 |
| 按当前方案先生产主体数量，另补切 X 件 | 该组有少件 | 主方案可生产，少的数量需另行安排 |
| 按当前方案生产，并确认超产 X 件的库存去向 | 该组多产 | 可生产，但多出的件数要确认处理 |
| 检查失败原因并人工复核后重新排版 | 程序未给出可下发方案 | 不要直接生产，交调度/技术处理 |
| 当前母板无法承接，转人工评估、外协或改规格处理 | 规格超过现有候选母卷宽度 | 需要更宽母卷、外协或修改规格 |

## 4. 状态、补切、超产的判断

| 情况 | 判断 |
| --- | --- |
| 状态为 `完成`，补切数为 0 | 当前方案数量满足订单 |
| 状态为 `完成`，补切数大于 0 | 方案少件，需要补切 |
| 状态为 `完成`，超产数大于 0 | 方案多件，需要确认多出件数去向 |
| 状态为 `失败` | 本组不能直接下发生产 |

注意：补切和超产是按件数判断，不是按重量判断。

这一页按母卷宽度汇总，用于备料和整体复核。

| 字段 | 说明 |
| --- | --- |
| 母板宽度 | 母卷宽度 |
| 分组数 | 使用该宽度的分组数量 |
| 单规格组数 | 其中单规格直接排的数量 |
| 多规格组数 | 其中多规格优化的数量 |
| 订单数 | 订单件数合计 |
| 算法产出数 | 方案产出件数合计 |
| 补切数 | 需要补切的件数合计 |
| 超产数 | 多产件数合计 |
| 母板消耗长度(mm) | 该宽度下总走料长度 |
| 真实利用率(%) | 该宽度整体材料利用率 |

## 6. 单规格结果

单规格结果适合查看某一种规格直接排的详细参数。

| 字段 | 说明 |
| --- | --- |
| 母板宽度 | 选用的母卷宽度 |
| 最优朝向 | 短边横放或长边横放 |
| 最优横向占宽 | 产品在母卷宽度方向占用多少 mm |
| 最优纵向定尺 | 产品沿走料方向的定尺长度 |
| 每条并排数 | 每条刀位并排产出数量 |
| 需要条数 | 需要多少条/道 |
| 总消耗长度(mm) | 本组总走料长度 |
| 余宽 | 母卷宽度扣除占用宽度后的剩余宽度 |

| 补切数 | 需要补切的件数 |
| 超产数 | 多产件数 |

## 8. 无法承接分组

如果某组失败且现有母卷无法承接，会写到这一页。

| 字段 | 说明 |
| --- | --- |
| 分组编号 | 失败组编号 |
| 品名 | 品名 |
| 厚度 | 厚度 |
| 规格种数 | 该组规格数量 |
| 当前母板宽度(mm) | 程序记录的最大/候选母卷宽度 |
| 超宽规格 | 无法放入的规格 |
| 最大短边(mm) | 超宽规格的短边尺寸 |
| 建议处理 | 人工、外协、改规格或更换更宽母卷 |

此页中的分组不能直接下发生产。

## 9. 重量和数量的关系

生产数量按走料长度和定尺长度确定：

```text
产出件数 = 刀数 × (走料长度 / 定尺长度)
```

重量用于吨位核算。预计用料重量优先使用输入表反算出的组密度：

```text
组密度 = 本组订单总重量 ÷ 本组订单总体积
预计用料重量 = 母卷宽度 × 走料长度 × 厚度 × 组密度
```

现场不能用重量反推件数下发生产，必须以报告中的刀位、走料长度和产出数量为准。
