# 钢板纵切排版优化系统

本项目用于读取实际生产状态 Excel，按品名、厚度和规格自动分组，选择可用母卷宽度，生成纵切排版方案、排版图、文本生产指令报告和汇总结果表。

## 快速运行

交付给操作人员时，推荐直接双击：

```text
run_client_workflow.bat
```

也可以在命令行运行同一个入口：

```powershell
python run_client_workflow.py
```

运行后会弹出 Excel 文件选择窗口，由操作人员选择需要排版的输入表。程序完成后会在 `outputs/client_runs/` 下生成本次运行目录。

也可以使用命令行入口：

```powershell
python scripts/main_actual_production.py --decoder-mode auto --panel-widths 1000,1240,1250,1500 --input data/实际生产状态表.xlsx
```

## 输入表要求

输入 Excel 默认读取第一个 Sheet，程序按前四列顺序读取。前四列必须为：

| 字段 | 含义 |
| --- | --- |
| 品名 | 材料/产品名称 |
| 规格 | 形如 `厚度*尺寸1*尺寸2`，例如 `0.7*328*340` |
| 片数 | 订单数量 |
| 重量 | 该规格总重量，交付使用时统一按 kg 填写，报告中换算为吨 |

卷料、特殊规格写法、无法解析的规格会进入剔除明细。

## 输出内容

每次运行会生成一个独立目录：

```text
outputs/client_runs/<输入文件名>_<时间戳>/
```

主要输出：

| 文件/目录 | 内容 |
| --- | --- |
| `*_结果.xlsx` | 全流程汇总、分组、策略、结果、失败组等工作表 |
| `排版图与报告/` 或 `artifacts/` | 每个成功分组的排版图和生产指令报告 |
| `*_cutting_report.txt` | 文本版生产指令单，包含任务信息、订单核对、阶段排刀、重量和确认栏 |
| `*_cutting_plan.png` | 对应分组排版图 |

报告中的重量口径：

| 字段 | 计算口径 |
| --- | --- |
| 预计用料重量 | 母卷全宽 × 阶段走料长度 × 厚度 × 组密度，包含余宽和尾料 |
| 产出重量 | 输入表该规格总重量 / 订单数量 × 本阶段产出数量 |
